연수 실습 · GitHub에서 수정하고 배포하기

지금 보고 있는 첫 화면의 파일 이름은 index.html입니다. 사이트 주소에 접속하면 이 화면이 열립니다.

  1. 저장소의 Code(파일 목록)에서 수정할 파일을 선택하고 연필 모양의 Edit(편집)을 누릅니다.
  2. 내용을 고친 뒤 Commit changes(변경 사항 저장)를 누릅니다. 설명에는 ‘첫 화면 안내 문구 수정’처럼 무엇을 바꿨는지 적습니다. 커밋은 변경 이력을 남기는 저장입니다.
  3. 최초 배포는 Settings(설정) → Pages에서 Deploy from a branch → main → /(root) → Save로 설정합니다. 이후 main에 저장된 수정은 자동 배포됩니다.
  4. Actions(실행 기록)에서 배포 성공을 확인한 뒤 사이트를 새로고침하고 링크와 버튼을 시험합니다. 저장 직후에는 배포에 시간이 걸릴 수 있습니다.

따라 하기: 첫 화면의 안내 문장 한 줄을 수정하고 커밋한 뒤, 사이트에 바뀐 문장이 나타나는지 확인해 보세요.

용어: 저장소는 프로젝트 보관함, main은 기준 버전이 쌓이는 작업 줄기, Pages는 웹사이트 게시 기능입니다. Git의 ‘인덱스’는 커밋할 변경을 준비하는 영역이며, 첫 화면 파일인 index.html과는 다른 뜻입니다.
